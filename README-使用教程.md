# 以撒中文控制台 desktop-v1.4.3（宿主桥修复版）

这是一个面向 Windows / Steam 版《The Binding of Isaac: Rebirth》的中文辅助控制台。它不会修改游戏文件，也不会安装 Mod；点击界面按钮时，工具会切换到游戏窗口，通过游戏内置调试控制台提交命令。界面只报告输入是否提交，实际效果请在游戏内确认。

## 前置要求

- Windows 10 或 Windows 11。
- Steam 版《The Binding of Isaac: Rebirth》。道具库按照 **Repentance** 整理，Repentance+ 也可使用，但新增内容可能未收录。
- Windows PowerShell 5.1 与 `mshta.exe`，两者通常由 Windows 自带。
- 游戏的内置调试控制台已开启。
- 建议使用普通权限运行游戏和本工具；如果游戏以管理员身份运行，本工具也需要相同权限，否则 Windows 可能阻止按键发送。

## 安装与启动

1. 完整解压 ZIP 到普通文件夹。不要在压缩包预览窗口里直接运行，也不要只取出单个文件。
2. 第一次使用建议双击 `一键环境检测.cmd`。
3. 启动游戏并进入一局，保持游戏内控制台处于关闭状态。
4. 在文件资源管理器中双击纯英文入口 `START.cmd`。不要直接从聊天文件链接或 ZIP 预览窗口运行。
5. 左下角显示“游戏运行中”后，选择分类并点击“给予”或“执行”。

## 开启游戏内置控制台

最省事的方法：完全关闭游戏，然后运行包内的 `开启游戏控制台.cmd`。脚本会在修改前创建 `options.ini.console-backup` 备份，并要求你确认。

也可以手动操作：

1. 完全关闭游戏。
2. 打开以下某个与版本对应的文件：
   - `文档\My Games\Binding of Isaac Repentance\options.ini`
   - `文档\My Games\Binding of Isaac Repentance+\options.ini`
   - `文档\My Games\Binding of Isaac Afterbirth+\options.ini`
3. 找到 `EnableDebugConsole=0`，改为 `EnableDebugConsole=1`。
4. 保存后启动游戏。键盘左上角的 `` ` / ~ `` 键应能打开控制台。

如果同时装有 Repentance 和 Repentance+，要修改你实际启动版本对应目录中的 `options.ini`。

## 界面功能

- **分类冻结**：继续使用常用精选、输出核心、生存防御、资源经济、地图探索、主动神器、跟班军团、趣味组合、调试能力、即时补给和楼层跳转 11 个分类。
- **本机 EID 导入**：点击右上角“导入 EID”，自动寻找 Workshop 836319872 或游戏 Mods 副本；也可手动选择目录。导入数据只写入 LocalAppData，不随工具上传或分发。
- **完整搜索**：导入成功后可搜索最多 732 个道具；支持中文、英文、拼音、首字母、ID 与命令。未导入时仍可搜索 74 个精选与所有命令。
- **通用队列**：卡片和手动栏都可加入队列；支持排序、修改次数、删除、保存方案和执行前摘要。
- **取消与恢复**：取消、失焦或输入失败时，队列会自动只保留未提交部分。

- **常用精选**：默认展示各分类的高强度选择；点击卡片右上角星标可以建立自己的收藏。
- **中文分类**：输出、生存、经济、探索、主动、跟班、趣味组合、调试、补给与楼层跳转。
- **排序**：每类按常用度与强度排列，S 级和核心道具优先。
- **搜索**：支持中文名、英文名、效果说明、道具 ID 与原生命令。
- **给予 / 移除**：使用 `giveitem c<ID>` 与 `remove c<ID>`。
- **手动命令**：底部可输入单条 Isaac 原生控制台命令，按 Enter 发送。
- **命令联动**：点击任意给予、移除或执行按钮时，底部输入框会同步显示该命令。
- **执行次数**：底部可用 `− / 次数输入框 / +` 设置 `1–99` 次，默认 1 次。
- **安全批量**：只有 `giveitem` 和 `spawn` 会批量执行；`debug`、`stage`、`kill`、`remove` 等会自动降为 1 次并给出提示。
- **实时进度**：队列抽屉显示当前步骤与已提交次数；历史保存请求与已提交数量。
- **两种发送模式**：“自动打开并关闭”适合日常使用；若控制台已经打开，可选择“控制台已打开（执行后关闭）”。两种模式执行后都会关闭原生控制台。
- **失败兜底**：自动发送失败时保留未提交部分；可复制命令并手动粘贴到游戏控制台。

## desktop-v1.4.3 队列与目录

1. 单击卡片打开详情；“立即执行”直接发送，“入队”只加入队列。
2. 队列可以拖动排序，也可以使用 ↑ / ↓；每个方案最多 200 步，最多保存 50 个方案。
3. 任意单行命令都可入队；风险标签仅提示，不拦截。命令最多 500 字符且不能包含换行。
4. 只有 `giveitem`、`spawn` 可以重复 2–99 次；其他命令自动变成 1 次。
5. `Ctrl+K` 聚焦搜索、方向键移动卡片焦点、Enter 立即执行、`Ctrl+Enter` 执行队列、Esc 关闭抽屉或弹窗。
6. EID 缓存和用户状态位于 `%LOCALAPPDATA%\IsaacChineseConsole`；删除缓存后可重新导入，不影响 EID Mod 本身。

## 正确使用姿势

1. 先进入一局，再发送命令；主菜单没有可接收道具的角色。
2. 点击工具按钮前，让游戏内控制台保持关闭。工具会负责打开、清空输入栏、输入、执行并关闭；开关键偶发写入的反引号也会在输入命令前清除。
3. 需要重复领取时，先设置执行次数，再点击卡片或发送命令。工具只打开一次控制台，在同一会话中连续执行，最后只按一次 `Esc` 关闭。
4. 次数超过 20 时界面会提示卡顿风险；这只是提醒，不会阻止。大批量生成实体可能让当前房间明显卡顿。
5. 发出命令后等待结果，不要快速连点。成功或部分成功后次数恢复为 1；完全失败时保留原次数，便于排查后重试。
6. `debug 3` 等调试命令是开关；即使次数设为 5，也只会执行 1 次，避免重复后把效果抵消。
7. 楼层跳转和“清空道具”会改变当前流程，使用前请确认存档状态。

如果自动模式没有生效，请使用兼容模式：先在游戏中按 `` ` / ~ `` 打开控制台，切回工具，把底部“发送模式”改为“控制台已打开（执行后关闭）”，再点击道具或发送命令。该模式不会在执行前按控制台热键，但仍会清空输入栏、执行命令并自动关闭控制台。

## 1.2.1 界面修复

底部手动命令栏已移入主界面的正常纵向布局，不再浮在功能卡片上方。滚动到列表最底部时，最后一排按钮会完整显示并可点击；窗口较窄时会自动隐藏次要提示文字，为输入框和发送按钮留出空间。

## 1.2.2 控制台关闭修复

执行命令后不再第二次发送 `` ` / ~ ``。截图验证表明，以撒在控制台输入状态下会把第二次热键当成普通的 `` ` `` 字符，因此控制台不会关闭。1.2.2 改为：物理 `` ` / ~ `` 键只负责打开控制台，命令执行完毕后使用物理 `Esc` 键关闭。

## 1.3.0 批量执行

- 新增全局执行次数 `1–99`，适合连续生成魂心、宝箱或重复给予可叠加道具。
- 仅允许 `giveitem`、`spawn` 批量执行；发送器会再次校验白名单，不能通过手动输入绕过。
- 批量期间实时显示完成进度，并把等待时间按次数动态延长，99 次也不会被旧的 8.5 秒超时提前中断。
- 全批成功记录实际次数；中途失焦或按键被拦截时显示“部分完成”，提醒不要整批重复领取。
- 成功或部分完成后次数自动回到 1；完全失败时保留次数。

## 常见问题

### 左下角一直显示“未检测到游戏”

确认游戏已经启动。1.1.1 起检测器会识别 `isaac-ng.exe`、`isaac-ng-x64.exe` 和 `isaac.exe`，并且状态灯失败也不会阻止实际发送。若使用兼容层、云游戏或非 Windows 原生版本，自动检测与窗口切换可能不可用。

### 显示已发送，但游戏没有反应

- 确认内置控制台已开启。
- 发送前让游戏内控制台保持关闭。
- 确认当前在一局游戏中，而不是主菜单。
- 游戏若以管理员身份运行，请右键启动器并选择“以管理员身份运行”。
- 尝试切换到英文键盘布局，关闭可能接管按键的输入法或覆盖层。

### 自动发送失败或超时

工具会自动复制命令。切回游戏，按 `` ` / ~ `` 打开控制台，按 `Ctrl+V` 粘贴并回车。然后运行 `一键环境检测.cmd` 获取报告。

### 次数设为 5，为什么 debug / stage / kill / remove 只执行一次

这是安全限制，不是故障。重复执行调试开关可能把效果再次关闭，重复跳层、清场或删除道具也可能造成不可逆结果。因此只有 `giveitem` 与 `spawn` 支持批量；界面和 PowerShell 发送器都会校验。

### 提示“仅完成 3/10”怎么办

表示前三次已确认执行，之后因游戏失去焦点、按键被拦截或等待超时而停止。不要直接按 10 次重试，否则会重复领取已经完成的部分；请确认游戏状态后把次数改成剩余的 7 次。

### Windows 或安全软件提示脚本风险

本包包含 PowerShell 脚本，因为它需要切换 Isaac 窗口并模拟键盘输入。脚本为纯文本，可直接用记事本检查。它不会联网，不会读取游戏存档，也不会修改游戏安装目录。`开启游戏控制台.cmd` 是唯一会修改游戏配置的工具，并且运行前会确认和备份。

### 收藏或历史没有保存

某些系统策略会禁用 HTA 的本地存储。这不会影响主要功能，只会让收藏和历史在关闭后重置。

## 安全与存档说明

- 使用调试控制台可能影响成就或解锁条件，建议用于娱乐、测试或已有备份的存档。
- 本工具不提供存档恢复功能。
- 不建议输入来源不明的 `lua` 或复杂控制台代码。
- 手动输入框每次只允许一条命令，最多 500 个字符，以减少误执行。

## 包内文件

- `START.cmd` / `start-console.ps1`：推荐启动入口，检查完整文件、启动 HTA、确认可见窗口并记录日志。
- `启动以撒中文控制台.cmd`：兼容入口，内部转交给 `START.cmd`。
- `IsaacConsole.hta`：中文图形界面。
- `desktop/`：界面样式、固定目录、状态、搜索、队列和 UI 模块。
- `send-command.ps1`：统一任务发送器，支持单命令与 JSON 队列任务。
- `import-eid-catalog.ps1`：从本机 EID 离线导入完整道具目录，不复制 EID 原始文件。
- `一键环境检测.cmd` / `环境检测.ps1`：只读检查运行环境并生成报告。
- `开启游戏控制台.cmd`：经确认后开启游戏控制台并备份配置。
- `README-使用教程.md`：本说明。
- `常见问题.txt`：适合快速转发的排障清单。
- `版本信息.txt`：版本与变更摘要。
- `RELEASE-desktop-v1.4.3.md`：本版本发布说明与人工验收清单。

## 分发建议

直接分发原始 ZIP；接收方应完整解压后运行。请不要把 `IsaacConsole.hta` 或 `send-command.ps1` 单独发出，否则启动检查和教程会缺失。
