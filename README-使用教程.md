# 以撒中文控制台 desktop-v1.5.0 使用教程

这是一个 Windows 独立控制台，不安装 Mod、不联网、不读取存档。它会切换到 Isaac 窗口，通过游戏内置调试控制台输入命令；界面只确认输入已提交，实际效果请在游戏内核对。

## 前置要求

- Windows 10 或 Windows 11，系统中保留 `mshta.exe`、Windows PowerShell 5.1 和 Windows Script Host。
- Steam 版 Repentance 或 Repentance+，并已开启游戏内置调试控制台。
- 游戏与本工具使用相同权限级别。

企业策略、精简系统或安全软件可能禁用 HTA、ActiveX 或模拟按键。遇到问题先运行 `一键环境检测.cmd`。

## 安装与启动

1. 完整解压 ZIP，不要从压缩包预览中运行。
2. 双击 `一键环境检测.cmd`，确认没有“错误”项目。
3. 完全关闭游戏，运行 `开启游戏控制台.cmd`；脚本确认后修改对应 `options.ini` 并保留备份。
4. 启动游戏并进入一局，让游戏原生控制台保持关闭。
5. 从文件资源管理器双击 `START.cmd`。

## 分类与搜索

- 物品：常用精选、全部收藏品、饰品、卡牌/符文、胶囊效果。
- 道具精选：输出核心、生存防御、资源经济、地图探索、主动神器、跟班军团、趣味组合。
- 控制台：调试能力、即时补给、楼层跳转。

内置目录包含 721/188/97/50，共 1056 项。没有 EID 或中文控制台 Mod 时，中文、英文、拼音、首字母、ID、命令搜索仍完整可用。搜索示例：`圣心`、`Sacred Heart`、`shengxin`、`sx`、`c:182`、`giveitem c182`、`t:1`、`k:1`、`p:0`。裸数字冲突稳定按 `c → t → k → p` 排序。

## 收藏、详情与移除

- 星标收藏会追加到“常用精选”，默认推荐仍保留。
- 收藏使用类型化键，不会把 `c:1` 与 `t:1` 当成同一对象。
- 收藏品与饰品提供 `remove c<ID>` / `remove t<ID>`；卡牌和胶囊不提供移除。
- 移除只影响本体，不会回滚已经产生的资源、实体、房间或生命变化。

## 命令队列

1. 卡片可立即执行或入队；底部也可输入任意非空、无换行、不超过 500 字符的单行命令。
2. 队列最多 200 步，可排序、删除、清空、保存和载入；最多保存 50 个方案。
3. `giveitem c<ID>` 与 `spawn` 可重复 1–99 次。
4. `giveitem t/k/p<ID>`、`remove`、`stage`、`debug` 与其他命令固定 1 次，UI 和发送器会分别归一。
5. 一个队列只打开一次控制台，严格按顺序提交，完成后只按一次 Esc。
6. 取消、失焦或输入被拦截时，只保留未提交的剩余步骤和次数；不要重跑整批。

快捷键：`Ctrl+K` 搜索，方向键移动焦点，Enter 立即执行，`Ctrl+Enter` 执行队列，Esc 关闭抽屉或弹窗。

## EID 与状态

“导入 EID”依次查找 Workshop `836319872`、游戏 Mods 副本，也可手选目录。EID 只补充说明，缓存为 `%LOCALAPPDATA%\IsaacChineseConsole\catalog-v2.json`，不复制原始文件；损坏时先读 `.bak`，再退回内置目录。

用户状态为 `%LOCALAPPDATA%\IsaacChineseConsole\state-v3.json`，包含收藏、最近 100 条历史、队列草稿、最多 50 个方案和界面状态。写入使用临时文件替换并保留 `.bak`；旧 `state-v2.json` 与 localStorage 可迁移且不会删除。

## 排障

- 没有窗口：确认完整解压并运行 `START.cmd`；查看 `%LOCALAPPDATA%\IsaacChineseConsole\launcher.log`。
- 已提交但无效果：确认已进入一局、控制台已开启、输入法为英文半角、权限一致。
- 自动模式失败：先在游戏中打开控制台，再选择“控制台已打开（执行后关闭）”。
- 手动兜底：复制底部命令，在游戏原生控制台中粘贴并回车。
